# **App Name**: Tabletop Tracker

## Core Features:

- Game Logging: Manually add game records with details such as game name, date played, players, and game-specific stats.
- Player Management: Maintain a list of players and their stats across all logged games.
- Session Summaries: AI-generated summaries of each play session, noting interesting events or exceptional performances as a tool.
- Game Statistics: View statistics for each game, including win rates, average scores, and player rankings.
- Match Result AI Assistant: Use AI to help create a text summary of the session report.
- Data Export: Ability to export all logged data for personal backup or analysis.
- Data Visualization: Displaying user and group trends through visualizations of the log data.

## Style Guidelines:

- Primary color: Forest green (#3F704F), evoking nature and strategy.
- Background color: Off-white (#F2F0EC), providing a neutral backdrop.
- Accent color: Burnt orange (#A66321), for highlights and important actions.
- Body and headline font: 'PT Sans', a modern and versatile humanist sans-serif suitable for various text elements.
- Use clear, geometric icons representing different game categories (strategy, card, dice, etc.).
- Clean, card-based layout with intuitive navigation.
- Subtle animations for transitions and feedback during game logging and data visualization.
